GitHub Auto-Publish Setup

One-time setup. After this, "Publish" will auto-deploy posts to your live site in 2 minutes.

Step 1: Create a GitHub Personal Access Token (3 min)
→ Click here to open GitHub token page
  • Set expiration: No expiration (or 1 year)
  • Scopes: tick "repo" (full repo access)
  • Click "Generate token" at the bottom
  • Copy the token (starts with ghp_)

Token is stored only in your browser (localStorage). Never sent anywhere except GitHub's API. To remove, clear browser data for this site.
